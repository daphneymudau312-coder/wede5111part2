# Lux Crown Hair Studio Website

This project is a classic, elegant salon website designed for a boutique hair studio. It presents the business professionally, shares service information, highlights the salon's aesthetic, and supports appointment requests.

## Project overview

Lux Crown Hair Studio is a boutique hair salon offering a mix of modern and traditional hair styling services, including braiding, natural hair care, haircuts, hair extensions, wig installation, styling for events, and general hair treatments. The website was designed to meet the business requirements of showcasing services, promoting the brand, and making appointment requests easy for clients.

## Included pages

- Home
- About
- Services
- Lookbook
- Packages
- Book Now
- Contact

## Features implemented

- Responsive multi-page website using HTML and CSS
- External stylesheet for consistent site styling
- Classic luxury visual identity with warm gold, ivory, and charcoal tones
- Navigation and CTA buttons for all main site pages
- Booking and contact forms
- Gallery and package sections for salon promotion
- Mobile-friendly layout with media queries and responsive columns
- JavaScript for mobile menu and form interaction

## Website design notes

The visual style follows a classic and premium salon aesthetic, using elegant serif headings, a warm cream background, and soft gold accents. The layout was structured to help content feel clear, luxurious, and easy to navigate across desktop, tablet, and mobile screens.

## Responsive design testing notes

The website uses media queries to adjust layout and typography at key breakpoints for desktop, tablet, and mobile screens.

- Desktop: multi-column hero, service cards, and package layout
- Tablet: reduced navigation complexity and two-column content arrangements
- Mobile: single-column stacking for content, forms, and image layouts

## How to run the website locally

1. Open the project folder in a browser directly, or use a local web server.
2. If using a local server, open the terminal in this project folder and run:
   python -m http.server 8000
3. Then open: http://localhost:8000
